把你上传的 **1 张「三合一拼图」**（闭合礼盒 + 开盒 + 膏体特写）拆成 3 张独立关键帧，做成了 **一条 12 秒、竖屏 9:16、一镜到底不剪辑** 的高级质感产品短片，并配好了两个平台要用的封面图。

## 二、成片长什么样（镜头结构）

全程**一个镜头拍完，中间没有任何剪辑和转场**，摄影机一路往前推：

| 时间 | 画面 | 摄影机动作 |
|---|---|---|
| 0–4 秒 | 红色丝绒礼盒闭合正视，金色缎带蝴蝶结 | 缓慢平稳向前推近 |
| 4–8 秒 | 盒盖掀开，露出盒内 6 支金色管身口红 | 继续推近 + 平滑下压转为俯拍 |
| 8–12 秒 | 单支口红金色管身旋转，红色膏体旋出 | 顺排列方向前移下降，收在膏体微距特写 |

全程保持：红金配色、纯黑丝绒背景、丝绒哑光质感、**金色粒子光斑环绕漂浮**、商业电影级布光与浅景深。

## 四、发布操作步骤（小白版）

**小红书**
1. 手机/电脑打开小红书 → 底部「+」→ 选「视频」
2. 从 `02_成片` 里选 `品牌落版` 那个 mp4
3. 封面：选「自定义封面」→ 上传 `封面_小红书_3x4_礼盒主图.jpg`
4. 填标题和正文 → 发布

**视频号**
1. 微信 → 发现 → 视频号 → 右上角「相机」图标 → 发表视频
2. 选同一个 `品牌落版` mp4
3. 封面：选「更换封面」→ 上传 `封面_视频号_9x16_礼盒主图.jpg`
4. 填描述 → 发表

> 两个平台都用**同一个视频文件**，封面各用各的尺寸即可。
