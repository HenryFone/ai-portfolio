# HenryFone · AI 个人作品集

这是一个**公开的 GitHub 作品集仓库**，用于展示我独立完成的 AI、产品、视觉、网页和研究类成果。

## 从哪里开始看

- [`index.html`](./index.html)：6 件精选作品的主展示页。
- [`projects/index.html`](./projects/index.html)：21 个补充公开项目的目录页。
- [`PUBLIC-STRUCTURE.md`](./PUBLIC-STRUCTURE.md)：用小白能看懂的话解释这个仓库公开了什么、别人能下载什么。
- [`发给HR的网址-粘贴用.md`](./发给HR的网址-粘贴用.md)：招聘表单可直接粘贴的作品集网址和使用说明。

## 公开范围

这个仓库的定位是“公开展示层”，不是我电脑上的完整工程备份。当前公开内容主要包括：

- 脱敏后的项目说明 Markdown 和静态项目说明页；
- 可以直接在浏览器打开的 HTML/CSS/JavaScript 演示；
- 经过筛选的图片、关键帧和成品视频；
- 原有 6 件精选作品的展示文件。

以下内容不放在当前公开版本中：

- API Key、Token、Cookie、Bearer 信息、账号密码和临时签名地址；
- 个人电脑路径、个人联系方式、真实客户资料和内部数据；
- EXE、ZIP、原始 Word/PPT/PDF 和未确认版权的工程素材；
- 微信私域工具、桌面置顶工具和授权机制逆向分析等不适合公开展示的项目。

## 一个非常重要的事实

本仓库是 **Public（公开仓库）**。所以别人不只是能看到网页，也可以：

- 下载仓库中的 HTML、CSS、JavaScript、Markdown、图片和视频；
- 克隆整个仓库；
- 查看公开提交历史。

因此这里放的是“可以公开的展示版”，不是“只能看不能下载的体验外壳”。真正不能公开的源文件应放在私有仓库或只保存在本机。

## GitHub Pages

主展示页使用仓库根目录的 `index.html`。首页已经链接到 `projects/index.html`，所以访客可以从精选作品继续浏览补充项目。

## 维护原则

1. 先在本机完成和验收，再把脱敏后的展示文件复制到本仓库。
2. 任何密钥、账号、Cookie 或私人资料都不进入公开仓库。
3. 没有证据的播放量、收入、客户数和商业结果不写成既成事实。
4. 品牌相关内容按概念作品、测试样片或个人练习展示，不代表官方合作或真实投放。
