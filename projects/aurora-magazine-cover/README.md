# AURORA杂志封面视觉设计

> 类型：海报 / 视觉设计

## 项目目标

把一份主观的杂志封面创意需求转成规格明确、可评审的 AI 视觉成品。

## 我的职责

独立完成创意转译、画幅和文字规格锁定、提示词编排、多轮生成筛选、排版和成品验收。

## 使用的 AI / 软件 / 技术

AI 图像生成和人工排版/校核；原附件未明确具体生成平台名称，不在此处猜测。

## 人工判断与修改

把柴犬姿态、灰色摄影棚、橙色服装和深海军蓝刊头拆成可执行约束；多轮比较后选择构图，并如实保留残余观感差异而不夸大为完全一致。

## 最终成果与业务价值

1 个工作日内交付 1 张封面成品，形成从模糊需求到可评审视觉稿的完整过程。本次未发现真实发行量或客户投放结果，暂不补写。
