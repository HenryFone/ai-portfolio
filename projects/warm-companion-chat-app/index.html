项目目标

把 AI 情感陪伴的产品想法做成可点、可聊天、可演示的高保真交互原型，验证陪伴场景的低门槛与有分寸体验。

我的职责

独立完成产品信息架构、角色人设、视觉设计、会话内容、交互逻辑、静态前端实现、API 桩分层和离线演示验收。

使用的 AI / 软件 / 技术

原生 HTML、CSS、JavaScript，mock.js 单一数据源、api.js API 桩、app.js 交互逻辑、内联 SVG 图标和设计令牌；无后端、无外部运行依赖。

人工判断与修改

用三栏结构承载会话历史、聊天区和话题模板；把打字机、loading、发送动画和面板折叠设为演示验收项；人工校准回复内容为健康、正向、有边界的陪伴表达，并把数据、视图和接口桩分开以便交接。

最终成果与业务价值

交付一套可离线运行的高保真原型，包含 6 段会话、5 个话题模板和按关键词分流的回复池，能够演示从一键开场到逐字回复的完整路径。本次未发现真实用户量、留存或商业化数据，不补写为业务结果。

交付文件与展示方式

公开版保留可运行的静态网页、必要的 HTML/CSS/JS、角色头像和脱敏说明；不包含真实后端、账号、个人数据或任何模型密钥。
