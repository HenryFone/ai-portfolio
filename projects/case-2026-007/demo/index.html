01
01 / Executive Summary

执行摘要：五条核心结论

AI 编程工具已完成从「尝鲜插件」到「默认基础设施」的跃迁。赛道真正的变化不在采用率，而在计费单位——从「人头席位」转向「Token 消耗」。这一次范式切换重写了整个商业模型。

核心判断 · The Verdict

2026 年，AI 编程赛道最重要的变化不是用户增长，而是 计费单位从「席位」迁移到「用量」。GitHub Copilot 于 6 月 1 日全面切换为 AI Credits 按量计费，标志着这个品类正式告别 SaaS 席位时代，进入云成本结构主导的新阶段——增长的天花板由此从「有多少开发者」变成「有多少 Token 可被变现」。

结论 01 · 采用
渗透接近饱和，增长引擎换挡

Stack Overflow 2026 调查（30,000+ 开发者）显示 83% 已使用至少一种 AI 工具，其中代码助手/智能体占 66%；JetBrains 2026 年 5–7 月对 15,000+ 职业开发者的调查显示 90% 每周至少使用一次 AI 编程智能体。拉新不再是瓶颈，付费转化、留存与用量深度才是。

结论 02 · 格局
三强割据，但份额在实时转移

Claude Code（$2.5B+ ARR）已超越 Cursor 同期规模成为收入第一，Copilot 以 4.7M 付费席位与 50M 总用户守住规模第一。Copilot 份额从 1 月 67% 降至 7 月 51%——绝对量仍在涨，相对份额却在被 Agent 原生工具持续侵蚀。

结论 03 · 变现
四层收入栈，用量层成为主引擎

个人订阅 → 企业席位 → API/用量 → 模型差价。2026 年最大的结构性变化是用量层从「弹性补充」升级为「计费中枢」：Copilot 各档位均含等值 AI Credits，Enterprise 组织内共享额度池，轻度用户的未用额度可抵扣重度用户——这实质上是一次毛利结构的重构。

结论 04 · 经济
推理成本是毛利税，但已非「无底洞」

公开测算显示 Cursor 早期年付 Anthropic API 成本 ~$6.5 亿 vs 收入 ~$5 亿（毛利率 -30%）；如今通过自研 Composer 模型 + 低价开源模型路由已转为轻微毛利转正，企业账户毛利为正、个人账户仍亏损——利润池正在明确向上迁移。

结论 05 · 趋势
模型方下场，是这个赛道最深的结构性威胁

Gartner 明确指出：2026 年前沿模型厂商已从上游供应商变成直接竞争者——Anthropic（Claude Code）、OpenAI（Codex）与它们曾经的客户在同一张牌桌上。这带来一个残酷的不对称：拥有模型的一方按「边际成本」定价，套壳方按「零售 API 价」采购。Cursor 约 20 名研究员基于 DeepSeek / Kimi / Qwen 训练 Composer 系列来对冲，正是这场挤压的最直接证据。

关于这批数字的三点提醒

一、口径不可混用。Stack Overflow 的「83% 使用至少一种 AI 工具」与 JetBrains 的「90% 每周使用 AI 编程智能体」看起来矛盾，实则测量对象不同——前者是全量开发者，后者是职业开发者且限定在「编程智能体」这一子类。引用时务必带口径。

二、Copilot 的收入是估算，不是披露。微软在 FY26 Q2/Q3/Q4 三次财报中分别公布了付费订户数、组织数与总用户数，但从未公布收入。任何写着「Copilot 年收入 XX 亿」的表述都是第三方测算，务必注明估算方。

三、时点差异会造成误判。本报告核心数据分布在 2026 年 2 月至 9 月的不同披露中（Cursor ARR 为 6 月口径，Copilot 付费数为 1 月口径）。横向比较时需注意这些数字并非同一时点。

读数要点：品类增速 37%，头部增速远超赛道

品类总盘年复合增速约 37%，而 Cursor 单家在 14 个月内做到 40 倍，Claude Code 在 3 个月内翻倍至 $2.5B。这种剪刀差只有一个解释：市场正在以远快于自然增长的速度向头部集中。对企业采购方而言，这是坏消息——你的议价能力正在下降，供应商替换成本在上升，且这种集中还在继续。

GitHub 官方文档
为什么切换是必然的

GitHub 的理由很直白：Copilot 已从编辑器辅助工具演变为能执行长时间、多步骤自主编码会话的智能体平台，旧的 Premium Request 计数方式「已难以为继」。

微软同时承认 agentic usage「正在成为默认」，带来更高的算力与推理需求。翻译成商业语言：成本结构变了，定价结构必须跟着变。

定价稳定性的代价

Cursor 的定价史是一份公开的压力测试：2025/6 Pro 固定 500 请求改为 Credit 制度，价格不变但 Claude 系模型有效容量从 ~500 降至 ~225；7 月 CEO 公开道歉并退款（单周超额 $350 案例）；9 月 取消 unlimited Auto。

2026/6 的 Teams 双轨重构（Standard / Premium 分层）是直接回应。八个月三次调价——这是套壳方在零售 API 价下的结构性困境。

为什么企业才是利润池

企业买的不只是模型质量，还有 SSO、SCIM、隐私保证、可审计性、采购支持、消费控制、部署选择与策略执行——这些能力不按比例推高推理成本，因此可以单独定价。

合同结构也在向此倾斜：GitHub 全组织共享额度池；Cursor 为企业客户预留共享用量；Devin Teams = 固定席位 + 共享按需额度。数千人团队可用轻度用户对冲重度用户，而非按最坏情况给每个人定价。

06
06 / Unit Economics

单位经济与核心挑战

这是整份报告中最反直觉的部分：「推理成本是无底洞」这个流行叙事在数据上并不成立。真正的成本差距来自「买 API」与「自有模型」的结构性不对称。

⚡ 关键事实核查：那个疯传的「$5,000/月」数字
$5,000 → $500

流传的说法：Forbes 报道 Cursor 内部分析发现，Anthropic 的 $200/月 Claude Code Max 订阅可消耗约 $5,000 计算量，被广泛当作 Anthropic 烧钱的证据。

但这个数字按零售 API 价计算，不是实际推理成本。在 OpenRouter 等开放推理市场，同等规模开源模型的竞争性定价约为 Anthropic API 价的 十分之一——而这些供应商仍需覆盖 GPU 成本并盈利。据此推算，最重度用户的实际推理成本约 $500。

关键区分：$5,000 对 Cursor 是真实的（必须按 Anthropic 零售 API 价采购），但对 Anthropic 不是。据称 Anthropic 官方数据显示平均用户每日 API 等价消费仅约 $6（月均约 $180），按十分之一实际成本计约 $18/月服务成本——对应 $20–200 的订阅价，平均用户已可盈利。

来源：Forbes 报道 + Martin Alderson（catchmetrics.io 联合创始人）分析 + aicostcheck.com 测算 · 转述自 blockbeats.info
利润池正在向上迁移

毛利为正。大额合同、共享额度池、稳定性溢价支撑毛利。Cursor 企业客户约占收入 60%。

✗ 个人账户

仍在亏损。个人开发者恰是能连续跑 Agent、加载巨型仓库、且刻意选用最贵前沿模型的重度用户。

TechCrunch 报道 Cursor 此前长期负毛利；引入自研模型 + 更廉价推理路由后，达到「仅轻微的」整体毛利转正。这个结构说明的不是「AI 不赚钱」，而是「不控制模型的人不赚钱」。

把数字换算成钱：为什么企业预算这么好批

按 $20 万年薪开发者计，Copilot Enterprise 席位为 $468/年。即使只兑现 27% 的提振（把 55.8% 砍半），也相当于 $54,000 等值产出——115× 回报；按完整的 55.8% 计则是 235×。

关键的分布特征：提振集中在初中级工程师的工作上，而他们恰恰是大型企业工程团队的主体。这意味着 AI 编程 ROI 最高的组织，正是初中级/资深比例偏大的团队——这构成了绝大多数大型企业。这也意味着：以资深架构师为主的小型精英团队，反而可能感受不到同等收益。

SWOT 与关键挑战

赛道的结构性优势与脆弱性同时被放大：采用率高到接近饱和，护城河却薄到切换成本低。

S优势 Strengths
  • 需求是刚需且高频83% 已使用，代码助手用户中 73% 每天使用；日活群体中 31% 每天用 ≥4 小时。黏性天然。
  • ROI 论证极其容易PR 周期 -75%、任务完成 +26–55.8%，企业多数在 3–6 个月内看到正回报。
  • 企业预算明确、合规解锁点清晰IP 赔偿、数据不用于训练、组织级模型配置是打通企业法务的关键三件套。
  • 增长速度快到前所未有Cursor 14 个月 40 倍，Claude Code 3 个月翻倍——历史上罕见的 B2B 爬坡速度。
W劣势 Weaknesses
  • 毛利结构性受压按零售 API 价采购模型的一方（Cursor）个人账户仍为负毛利，只能靠自研模型与开源模型路由对冲。
  • 底层模型依赖第三方模型方下场自营后，套壳方同时失去成本优势与产品叙事——这是最本质的脆弱性。
  • 同质化严重、切换成本低开发者同时跑多个工具（VS Code 75.9% 未被侵蚀即证据）；定价频繁调整进一步削弱信任。
  • 信任与安全缺口仅 6.6% 愿在重要决策上信任 AI；29.1% Python 生成代码含安全弱点，审查成本被转移给了用户。
O机会 Opportunities
  • 从补全走向任务级自主交付Agent 现可在人类介入前完成约 20 个自主动作（六个月内翻倍）；Rakuten 在 1,250 万行 vLLM 代码库上 7 小时自主完成、99.9% 数值准确率。
  • 长时程任务打开新经济性Agent 会话从数分钟延长到数小时乃至数天，使原本「不经济」的遗留代码迁移、大规模重构变得可行。
  • 多智能体协同Gartner 记录多智能体系统咨询量从 2024Q1 到 2025Q2 激增 1,445%；57% 组织已部署多步智能体工作流。
  • 企业合规与私有部署差异化SOC2 / GDPR / ISO27001、本地与 VPC 隔离部署，在金融等强监管行业构成真实壁垒。
  • 按结果计费的可能性Replit 已按工作量定价并叠加基础设施变现，验证了「卖成果而非卖交互」的可行性。
T威胁 Threats
  • 模型方下场（最高级别）Gartner 明确列为 2026 年第一大趋势：前沿模型厂商从上游供应商变为直接竞争者，Anthropic / OpenAI 与其客户同台。
  • 大厂生态捆绑微软把 Copilot 嵌入整个开发者工作流；一个已在用 GitHub 的开发者等于半只脚已进 Copilot，激活成本只是开关与账单。
  • 价格战与成本不可预测开发者已出现单月 $200 / $400 / 逾 $1,400 的超额账单报告；21% 组织选择增加支出，27% 已按工作类型分流模型。
  • 供给侧过剩逾 800 家获投 AI 智能体初创公司，多数带编码产品，但收入集中度却已接近成熟市场——长尾几乎无生存空间。
  • 企业采购集中化McKinsey 2026 调研显示成熟 AI 战略的组织正主动减少智能体供应商数量，每个工作流类别收敛到一到两家，惩罚仅有边际差异的后来者。

趋势展望：未来三段式演进

基于趋势生命周期映射与采用曲线的前瞻判断。以下为场景式推演，非确定预测。

近期 · NOW · 0–12 个月

按量计费成为品类标配

Copilot 已于 2026/6/1 完成切换，Cursor、Devin 均已采用 Credit 机制。席位包将退化为「最低消费门槛」，用量成为真正的收入函数。

  • 组织级共享额度池 + 预算上限成为企业标配
  • 模型路由从「高级功能」变为「成本治理基础设施」
  • 补全类功能继续免费，用量层承接全部增量收入
  • 厂商间计费透明度成为竞争维度（账单可预测性）
中期 · NEXT · 12–24 个月

模型层与套壳层的最终裁决

Gartner 提出的未解问题将给出答案：若前沿模型性能持续快于编排技术演进，纵向整合者复利式扩大优势；若编码专用/蒸馏模型以显著更低成本达到「够用」，模型层将快速商品化，价值上移至工作流编排与开发者体验。

  • 自研模型从「对冲手段」变为「战略必需品」
  • 企业采购集中化，每个工作流收敛到 1–2 家供应商
  • Agent 覆盖 SDLC 全域：代码评审、测试、验证、CI 生成
  • 并购加速，行业进入 12–20 家规模玩家阶段
远期 · LATER · 24 个月+

价值计量从「座位」转向「交付成果」

Gartner 同时提醒：不要用活动或数量指标（生成行数、接受率）评估智能体成效。当 ROI 评估从任务层转向团队交付流与业务结果时，计费单位迟早跟随价值单位迁移。

  • 按成果/任务量计费，取代按席位与 Token
  • 与 CI/CD、项目管理、需求系统深度整合
  • 上下文工程成为核心资产（可信上下文 = 项目目标 85% + 代码文档 73%）
  • 赢家由单位经济与留存壁垒决定，而非模型榜单排名
选
如果你要选工具

别只看榜单排名——看组织级额度池、成本治理能力与合规认证（SSO / IP 赔偿 / 数据隔离），这三项决定你第二年的账单和法务风险。同时预留预算弹性：Agent 模式的月度成本波动可能超出预期，已有开发者出现单月逾 $1,400 的超额账单报告。

做
如果你要做产品

最值得押注的不是又一个补全工具，而是成本效率——模型路由、自研/蒸馏模型、上下文缓存。Gartner 指出的未解问题正是：当模型层商品化，成本工程将成为应用层唯一可持续的护城河。Cursor 用约 20 人做出 Composer 1.5，是目前唯一可验证的正面样本。

投
如果你看投资

估值锚已经变了。Cursor $50B 估值对应约 25× ARR，这个倍数只在「持续 3 倍级年增长 + 毛利持续改善」同时成立时才合理。而 Copilot 份额从 67% 降到 51% 说明：这个赛道的分发优势正在以肉眼可见的速度贬值。
