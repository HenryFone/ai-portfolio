B端后台管理系统可视化设计规范

网页 / 设计规范

打开演示页

项目目标

把 B 端后台可视化中的颜色、间距、图标、图表和页面规则整理成可复用的工程规范，方便前端、设计师和 AI 编码工具协作。

我的职责

独立完成需求抽象、Design Token 分层、图标与图表规范、四个模板页、HTML 展示和交付说明。

使用的 AI / 软件 / 技术

以 Ant Design 设计体系为基础，使用 HTML、CSS、SVG 组织可运行展示；AI 仅作为辅助整理与编码，原附件未明确具体模型名称。

人工判断与修改

先定义语义层和视觉层，再组合组件；把换肤、暗色主题、图标语义、图表层级和模板页规则写成可执行约束，而不是只展示静态效果。

最终成果与业务价值

可核实交付包括 50 枚通用图标、独立图表视觉规范和 4 个标准模板页，并沉淀为工程级 HTML 规范文档。本次未发现真实客户上线数据，暂不补写。
