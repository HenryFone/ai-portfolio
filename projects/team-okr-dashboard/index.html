团队OKR雷达图看板

网页 / 数据看板

打开演示页

项目目标

用一页可打开的雷达图，把团队目标值与实际值的差距可视化，并支持多维状态快速浏览。

我的职责

负责数据结构设计、雷达图几何计算、视觉层级、交互和单文件交付。

使用的 AI / 软件 / 技术

HTML、CSS、JavaScript 和 SVG；AI 可用于辅助拆解需求和生成初稿，但坐标、比例、交互和展示结果由人工核验。

人工判断与修改

使用 SVG 和数学计算而不是静态截图，处理坐标顶点、刻度、透明度、标签位置和基础响应式规则；逐项检查数据替换后图形是否仍然成立。

最终成果与业务价值

交付单文件 HTML 数据可视化看板；原附件记录约 452 行、20 KB 的轻量成品。本次未发现真实组织绩效数据或业务指标，暂不补写。

交付文件与展示方式

公开展示时可保留示例数据和前端源码；真实团队目标、姓名、部门和绩效数据必须替换为虚构数据或留在私有版本。
