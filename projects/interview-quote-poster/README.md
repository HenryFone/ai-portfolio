# 长访谈金句手绘长图

> 类型：网页 / 内容视觉化

> 这是公开作品集版本；只保留脱敏后的说明、展示页和成品素材。没有证据的指标不补写。

## 项目目标

把高信息密度的长访谈整理成可阅读、可打印、可复用的金句视觉长图，同时保留每句话的原始语境。

## 我的职责

负责通读文字稿、提炼 18 句金句、结构化编排、视觉隐喻设计、HTML/CSS/JavaScript 实现和验收。

## 使用的 AI / 软件 / 技术

AI 辅助提炼和视觉构思、HTML、CSS、JavaScript；具体模型和原始访谈来源未在补充中猜测。

## 人工判断与修改

不只截取漂亮句子，而是回到上下文核对含义；人工复核改写、段落层级、黑白打印效果和手绘图与文字的对应关系。

## 最终成果与业务价值

交付单文件 HTML 长图，覆盖约 4 小时访谈文字稿中的 18 句代表性内容，并为每句补充手绘隐喻和语境解读。本次未发现阅读量或传播数据，暂不补写。

## 交付文件与展示方式

公开版应确认访谈文字和肖像/素材授权后再发布；未授权原始逐字稿和可识别的个人信息不公开。
