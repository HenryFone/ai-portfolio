玩法说明

三分钟看懂这场讨伐战
① 建档，领到你的起点

填入身高体重和运动习惯，用 Mifflin-St Jeor 公式估算每日总消耗（TDEE）。猪妖血量 = 距目标的体重，血条 24 段，瘦一公斤掉一截。

② 每天一句话打卡

「早上两个鸡蛋一碗米饭，晚上跑步 30 分钟」——自动解析热量与蛋白 / 碳水 / 脂肪 / 纤维，可逐条改完再入库。原文不会被保存，只存结构化结果。

③ 每周反向校准 TDEE

公式只是猜测。引擎每天拿「记录的摄入 vs 真实体重变化」（1 kg 脂肪 ≈ 7700 kcal）做能量平衡对账，用 14 天滚动窗口 + EWMA 反解出只属于你的 TDEE，打卡越久越准，「我的数据」页能看到收敛全过程。

军衔与勋章

每条记录都是军功：新兵 → 上等兵 → … → 将军（150 条）。勋章由数据自动解锁——连续打卡、缺口达标、晨重规律、训练累计、校准样本，全部达成时战报会自动弹出。

数据与隐私

全部数据存在你自己的资料库数据表（身体档案 / 每日记录 / 常吃食物三张），可随时在「我的数据」页导出 JSON / CSV 备份，或导入恢复；体质画像只是行为统计，不构成医学建议。
