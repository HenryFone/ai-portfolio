# 金殿夺印-3D古风AI短剧-作品集

> 类型：视频 / AI 短剧

> 这是公开作品集版本；只保留脱敏后的说明、展示页和成品素材。没有证据的指标不补写。

## 项目目标

把古风短剧脚本拆成可执行镜头卡，完成角色、场景、对白、配乐和镜头节奏统一的 AI 短剧。

## 我的职责

负责故事与 14 镜拆解、角色和场景连续性、提示词、图生视频、TTS 对白、配乐、后处理、工程说明和质量检查。

## 使用的 AI / 软件 / 技术

原附件明确记录 Flova MCP（Wan 3.0 图生视频）、本地 TTS、numpy 算法配乐、OpenCV、Python 和 HTML 展示。

## 人工判断与修改

每个镜头写清时间、画面、台词、音效和失败预案；先预览镜头再串联，控制角色、镜头和色彩连续性；人工检查声音、节奏、字幕/水印和成片规格。

## 最终成果与业务价值

可核实成片规格为 75.000 秒、1280×720、16:9、30fps、H.264 + AAC 192k 立体声、14 镜、31.6 MB，并配套约 1.1 万字复刻文档。本次未发现真实播放或商业发行数据，暂不补写。

## 交付文件与展示方式

公开版可放成片、镜头表和脱敏教程；TTS 音频、临时资源地址、未授权音乐/字体、工程缓存和可执行文件不公开。
