01 / 设计理念

让屏幕先安静下来，人才能安静下来

夜间的界面不该刺激眼睛。所以整套稿子只做三件事：把底色压深、把光做得流动、把层次交给透明度。

#0F172A

深空暗色

底色是深空蓝黑 #0F172A，不是纯黑。留出可以被极光点亮的暗部，也让文字对比度保持柔和。

极光流体

全套只用了 1 张 AI 生成图——垂直极光夜空。首页与播放页共用同一张，上半部流光、下半部压深，让内容有落点。

玻璃拟态

卡片用 8% 白填充 + 12% 白描边 + 24px 背景模糊 + 1px 内高光。层次靠透明度叠出来，不靠多加一种颜色。

03 / 四个场景

从一个夜晚的四个瞬间

首页告诉你怎么睡、播放页陪你呼吸、混音台让你调出自己的声场、报告页告诉你昨晚睡得怎么样。悬停画面上的编号，可以看它标的是哪一块。

01 首页 · 夜晚的入口

今夜首页

打开 App 的第一秒要让人慢下来。极光从左上斜落，下半屏渐变压深到几乎全暗，所有文字与卡片都落在暗部——不是为了好看，是为了让眼睛不被亮部刺到。

  • 1睡眠计划玻璃卡　计划入睡 23:15、目标时长 8h 00m，右上角用状态徽章交代「已就绪」
  • 2为你推荐　深海睡眠 / 雨夜入眠 / 渐进放松，渐变圆角图标 + 时长，一屏三选
  • 3昨夜回顾条　87 分迷你环 + 7h 32m，把底部收口，点进去就是报告页
02 交互 · 跟着光球呼吸

呼吸引导播放

全屏极光压暗到 55%，画面上只留一颗发光的球。球随呼吸节奏胀缩，「吸气 / 屏息 / 呼气」在球心轮换——用户不需要读说明，看着光就够了。

  • 1三层光　最外径向光晕 + 两圈柔光环 + 球体自身的多层辉光投影
  • 2呼吸球　紫色径向渐变 + 左上角内高光，让平面圆有体积感；外发光用星云紫
  • 3进度与控制　第 4 轮 / 共 8 轮、01:12 / 03:00，缩放 · 上一首 · 播放 · 下一首 · 循环
03 工具 · 叠加自己的声场

混音实验室

四条音轨各自独立，正在播的那条用紫色描边 + 外发光标出来，一眼能看出主音轨是谁。滑块填充用靛蓝到极光紫的渐变，并在末端加一层同色辉光。

  • 1音轨卡　雨声 72% / 海浪 48% / 森林 30% / 营火 15%，渐变圆图标区分音色
  • 2总音量　统一控制，标注「睡前 30 分钟淡出」，把功能和助眠场景绑在一起
  • 3保存为「今夜音景」　页面唯一的主行动按钮，实心渐变 + 紫色投影
04 复盘 · 昨晚睡得怎么样

睡眠报告

评分环用 SVG 描边画出来，阶段柱严格按分钟数等比。页面上每个数字都能互相对上——报告页最怕的就是数字自相矛盾。

  • 187 分评分环　SVG stroke-dasharray 画出 87% 弧长，起点在 12 点方向
  • 2睡眠阶段　深睡 1h52m / 浅睡 4h06m / REM 1h34m / 清醒 28m，柱高按分钟等比、底对齐
  • 3指标与洞察　时长 7h32m、入睡 12m、觉醒 3 次；底部一条连续达标提示

05 / 数据与技术

每个数字都对得上

睡眠数据自洽表

  • 计划时长 8h 00m = 深睡 1h52m + 浅睡 4h06m + REM 1h34m + 清醒 28m
  • 净睡眠 7h 32m = 8h 00m − 清醒 28m，与指标卡、首页回顾条一致
  • 阶段柱高度按分钟等比：浅睡 246 分钟 = 满高，深睡 112 分钟 ≈ 0.46 倍
  • 4-7-8 呼吸：8 轮 × 22.5 秒 ≈ 03:00，与首页入口「3 分钟」标注一致
